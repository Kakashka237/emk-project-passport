# ADR-001: Выбор стандарта HL7 FHIR R4 для модуля интеграции с лабораториями

**Статус:** принято.

## Контекст и проблема
АИС «ЭМК» получает результаты анализов от нескольких лабораторий. Каждая передает данные в своем формате
(CSV, XML, PDF-бланк) со своими кодами показателей и единицами. Результаты нельзя автоматически привязать к карте,
сравнивать в динамике и проверять, а подключение новой лаборатории требует отдельной доработки.

## Решение
Шлюз принимает результаты только в HL7 FHIR R4 (DiagnosticReport, Observation, коды LOINC, единицы UCUM)
через REST API (HTTPS, mTLS, OAuth 2.0). Для лабораторий без FHIR на стороне шлюза пишется адаптер-конвертер.

## Отклоненная альтернатива
Обмен файлами с отдельным парсером для каждой лаборатории: число парсеров растет вместе с числом лабораторий,
нет единых кодов показателей, нет подтверждения доставки и аудита доступа, которых требует 152-ФЗ.

## Последствия
Нужны валидация входящих ресурсов по FHIR-профилям и справочник соответствия локальных кодов кодам LOINC.
